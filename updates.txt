Admin Panel Reindex Implementation Guide
Objective
Add "Reindex" buttons to the Admin Dashboard for various entities (Orders, Products, Categories, Users). This feature allows the admin to manually trigger a re-indexing of data into Elasticsearch if search results become out of sync.

Reindex Endpoints
1. Orders
URL: /api/orders/admin/reindex
Method: POST
Auth: Admin Only
Context: Use when order search or filtering is incorrect.
2. Products
URL: /api/product/reindex
Method: POST
Auth: Admin Only (likely protected by SecurityConfig)
Context: Use when product search (by name, price etc.) is incorrect.
3. Categories
URL: /api/category/reindex
Method: POST
Auth: Admin Only
Context: Use when category search is not working.
4. Users
URL: /api/admin/users/reindex
Method: POST
Auth: Admin Only
Context: Use when user list searching is desynchronized.
Implementation Details
Service Layer (Example: adminService.js)
// Generic reindex function or separate functions
export const reindexEntity = async (type) => {
  let url = '';
  switch(type) {
    case 'orders': url = '/orders/admin/reindex'; break;
    case 'products': url = '/product/reindex'; break;
    case 'categories': url = '/category/reindex'; break; // check singular/plural in your axios setup
    case 'users': url = '/admin/users/reindex'; break;
    default: throw new Error('Invalid type');
  }
  
  return axiosInstance.post(url);
};
UI Component (Admin Settings)
You can create a grouped "Maintenance" card.

const ReindexGroup = () => {
    const handleReindex = async (type, label) => {
        if(!confirm(`${label} yeniden indekslenecek. Onaylıyor musunuz?`)) return;
        try {
            await reindexEntity(type);
            alert(`${label} başarıyla indekslendi.`);
        } catch(e) {
            alert('Hata oluştu.');
        }
    };
    return (
        <div className="card p-4">
            <h3 className="font-bold mb-4">Arama Motoru Bakımı (Re-Index)</h3>
            <div className="flex gap-2 flex-wrap">
                <Button onClick={() => handleReindex('orders', 'Siparişler')}>
                    Siparişleri Re-Indexle
                </Button>
                <Button onClick={() => handleReindex('products', 'Ürünleri Re-Indexle')}>
                    Ürünleri Re-Indexle
                </Button>
                <Button onClick={() => handleReindex('categories', 'Kategorileri Re-Indexle')}>
                    Kategorileri Re-Indexle
                </Button>
                <Button onClick={() => handleReindex('users', 'Kullanıcıları Re-Indexle')}>
                    Kullanıcıları Re-Indexle
                </Button>
            </div>
        </div>
    )
}
