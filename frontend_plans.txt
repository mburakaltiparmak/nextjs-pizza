🔴 KOD KALİTESİ & TEMİZLİK (P0 - QUICK WINS)
================================================================================
Hızlıca tamamlanabilecek, kod kalitesini artıracak işler.

7. **[P0-7] Duplicate Axios Instance Birleştirme**
   - **Sorun:** `src/lib/axios/config.js` ve `src/lib/api/axios-instance.js` aynı işi yapıyor.
   - **Çözüm:** Tek bir merkezi axios config dosyası kullanılacak.
   - **Dosyalar:** 
     - KALACAK: `src/lib/axios/config.js`
     - SİLİNECEK: `src/lib/api/axios-instance.js`
   - **Etki:** Tüm import'lar güncellenmeli.

8. **[P0-8] Console.log Temizliği**
   - **Sorun:** Production build'de gereksiz console.log'lar kalıyor.
   - **Çözüm:** 
     - ESLint rule: `no-console: ["error", { allow: ["warn", "error"] }]`
     - Veya: `babel-plugin-transform-remove-console` (production only)
   - **Alternatif:** Custom logger utility (`/lib/utils/logger.js`)

9. **[P0-9] Unused Imports & Variables Temizliği**
   - **Hedef:** IDE warning'lerinin sıfırlanması.
   - **Araç:** `eslint --fix` + IDE cleanup

================================================================================
🔴 GÜVENLİK (P0 - KRİTİK)
================================================================================
Production öncesi mutlaka tamamlanması gereken güvenlik önlemleri.

10. **[P0-10] Security Headers (next.config.js)**
    - **Hedef:** XSS, Clickjacking ve diğer saldırılara karşı koruma.
    - **Eklenecek Headers:**
      ```javascript
      // next.config.js
      async headers() {
        return [
          {
            source: '/:path*',
            headers: [
              { key: 'X-Frame-Options', value: 'DENY' },
              { key: 'X-Content-Type-Options', value: 'nosniff' },
              { key: 'X-XSS-Protection', value: '1; mode=block' },
              { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
              // CSP için detaylı analiz gerekli
            ],
          },
        ];
      }
      ```

11. **[P0-11] XSS Prevention - Input Sanitization**
    - **Riskli Alanlar:** Order notes, address fields, user inputs
    - **Çözüm:** `DOMPurify` veya `sanitize-html` kullanımı
    - **Dosyalar:** Form component'leri

12. **[P0-12] Redux DevTools Production Disable**
    - **Sorun:** Production'da Redux DevTools açık kalmamalı.
    - **Çözüm:** `store.js`'de environment check
    ```javascript
    devTools: process.env.NODE_ENV !== 'production'
    ```

🚀 SIRADAKİ GÖREVLER (P1 - YÜKSEK ÖNCELİK)
================================================================================
E-ticaret deneyimini iyileştirmek için yapılacak UX çalışmaları.

13. **[P1-1] Loading States Standardization**
    - **Hedef:** Kullanıcı beklerken boş ekran yerine "Skeleton" ekranlar göstermek.
    - **Plan:** `useLoadingManager` hook yazılacak.
    - **Kapsam:** Sayfa geçişleri, veri yüklemeleri, form submit'ler.

14. **[P1-2] Advanced Filtering**
    - **Hedef:** Menü sayfasında Fiyat Aralığı, Stok Durumu filtreleri.
    - **Backend:** `GET /api/product/search` hazır.
    - **Frontend:** Sidebar Filter component yapılacak.

15. **[P1-3] Form Validation Centralization**
    - **Sorun:** Zod schema'ları dağınık durumda.
    - **Çözüm:** `/lib/validations/` klasörü altında merkezi yönetim.
    - **Dosyalar:**
      - `/lib/validations/auth.js` (login, register)
      - `/lib/validations/order.js` (checkout, address)
      - `/lib/validations/product.js` (admin panel)

16. **[P1-4] Selector Optimization**
    - **Hedef:** Unnecessary re-render'ların önlenmesi.
    - **Yöntem:** `useAppSelector` kullanımlarının audit'i.
    - **Araç:** React DevTools Profiler

🟡 UX İYİLEŞTİRMELERİ (P2)
================================================================================
Kullanıcı deneyimini artıracak özellikler.

17. **[P2-1] Order Tracking Page (Müşteri)** ✅
    - **Hedef:** Müşterinin sipariş durumunu UUID ile takip edebilmesi.
    - **Route:** `/track/[uuid]`
    - **Özellikler:**
      - Login gerektirmez (UUID ile erişim)
      - Real-time durum güncellemesi (Socket.IO ile)
      - Timeline görünümü
      - Guest order cancellation (email verification)

18. **[P2-2] Admin Notification Sound** ✅
    - **Hedef:** Yeni sipariş geldiğinde ses bildirimi.
    - **Kütüphane:** `use-sound` veya native Web Audio API
    - **Koşul:** Socket.IO `order_created` event'i

19. **[P2-3] Optimistic Updates**
    - **Hedef:** Sipariş durum değişikliklerinde anında UI feedback.
    - **Kapsam:** Admin order status update
    - **Yöntem:** Redux action'da optimistic update + rollback on error
